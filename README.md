# Iran Dashboard

Next.js dashboard application for the local workflow stack.

## Prerequisites

- `nvm` is installed; use it to activate Node before running `npm`, `node`, or `npx`.
- A compatible Node.js version for Next.js 16 and the installed dependencies.
- npm.

Check the runtime before running project commands:

```sh
nvm version
nvm list
nvm use <version>
node --version
npm --version
```

## Development

Install dependencies when needed:

```sh
npm install
```

Start the dashboard:

```sh
npm run dev
```

The default URL is:

```text
http://localhost:3000
```
